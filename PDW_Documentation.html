1. 🎯 Overview

This is a Pulse Descriptor Word (PDW) Simulator that simulates how radar systems work in the real world. It creates realistic radar data by:

  • Simulating 5 radar emitters and 1 sensor receiver
  • Calculating true physical parameters (distance, angle, signal strength, etc.)
  • Adding realistic measurement noise to simulate real sensors
  • Exporting data to CSV for analysis

3. 🔄 How Data is Generated

Phase 1: Configuration & Initialization

  1. Load settings from dataconfig.yaml
  2. Create 5 radars with properties (position, power, frequency, etc.)
  3. Create 1 sensor with detection and error properties
  4. Calculate trajectories (where they move over time)
  5. Generate pulse times (when radars emit pulses)

Phase 2: Simulation Loop

For each pulse emitted by each radar:

Step 1: Calculate TRUE values (perfect physics, no noise)
Distance: d = √[(x_sensor - x_radar)² + (y_sensor - y_radar)²]
Angle: θ = arctan2(y_sensor - y_radar, x_sensor - x_radar)
Amplitude: P = P₀ + G(θ) - 20·log₁₀(d)
TOA: t = pulse_time + d/c
Frequency: f = f₀ + Δf_doppler
Step 2: Detection Check (Probabilistic)
Signal Strength Detection Probability
> -65 dBm 100% (always detected)
-65 to -70 dBm 100%
-70 to -75 dBm 90%
-75 to -80 dBm 70%
< -80 dBm 50%
Step 3: Add Noise (if detected)

This is where realistic measurement errors are added!

Phase 3: Export

Save all detected and measured pulses to CSV file with columns:

  • Name (radar identifier)
  • Freq(MHz)
  • PW(µs) - Pulse Width
  • Azimuth(°)
  • Power(dBm)
  • PRI - Pulse Repetition Interval

4. 🔊 How Noise is Added

Key Concept: Two Types of Errors

Every measurement has TWO error components added:

A) Systematic Error (ε_sys) - Predictable

Type Formula Example Use
Constant ε(t) = C Fixed calibration offset
Linear ε(t) = C + R·t Sensor drift over time
Sinusoidal ε(t) = A·sin(2πf·t + φ) Periodic interference

B) Arbitrary Error (ε_arb) - Random

Type Distribution Description
Gaussian ε ~ N(0, σ²) Most common! Bell curve distribution
Uniform ε ~ U(-a, +a) Equal probability across range

Measurement Equation:

Measured Value = True Value + ε_sys + ε_arb

Example: Amplitude Measurement

TRUE amplitude (perfect) = 35 dBm + Systematic error = 0 dBm (configured as constant 0) + Arbitrary error = +1.2 dBm (random from Gaussian, σ=2 dBm) = MEASURED amplitude = 36.2 dBm Next measurement might be: 35 + 0 + (-0.8) = 34.2 dBm (different random value!)

5. 📊 Noise Parameters (from dataconfig.yaml)

Parameter Systematic Error Arbitrary Error Meaning
Amplitude Constant: 0 dBm Gaussian: σ = 2 dBm ±2 dBm random noise
TOA Constant: 0 s Gaussian: σ = 5 ns ±5 nanosecond timing jitter
Frequency Constant: 0 Hz Gaussian: σ = 1% ±1% frequency error (~±15 MHz for 1.5 GHz)
Pulse Width Constant: 0 s Gaussian: σ = 25 ns ±25 nanosecond width error
AOA Constant: 0° Gaussian: σ = 3.5° ±3.5 degree angle error

Understanding Gaussian Distribution (68-95-99.7 Rule)

  • 68% of measurements fall within ±1σ of true value
  • 95% of measurements fall within ±2σ of true value
  • 99.7% of measurements fall within ±3σ of true value

Example for Amplitude (σ = 2 dBm):

  • 68% of measurements: within ±2 dBm
  • 95% of measurements: within ±4 dBm
  • 99.7% of measurements: within ±6 dBm

ADD NOISE Amplitude: -68 + 0 + 1.2 (random) = -66.8 dBm TOA: 0.000608716 + 0 + 0.0000000023 = 0.000608718s Frequency: 1500 + 0 + 8.5 (random) = 1508.5 MHz Pulse Width: 100.000 + 0 + 0.018 (random) = 100.018 µs AOA: 43.4 + 0 + 2.3 (random) = 45.7° 5. SAVE TO CSV Radar1,1508.5,100.018,45.7,0.0,-66.8,0.0006
